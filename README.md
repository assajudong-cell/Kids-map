# 키즈존 300 지도

아이와 가볼 만한 국내 여행지 300곳(가이드북 "KIDS ZONE" 목차 기준)을 테마·권역별로 보는 지도입니다.

- `index.html`: 지도 페이지 (Leaflet, 지도 타일 © OpenStreetMap © CARTO)
- `kids-zone-300.csv`: 전체 장소 목록 (번호, 권역, 지역, 장소, 책 페이지, 좌표, 테마)
- `kids-zone-300-google-mymaps.csv`: 구글 내 지도 가져오기용 파일

좌표 중 일부는 대략 위치이며, 지도에서 점선 테두리 핀으로 표시됩니다.
