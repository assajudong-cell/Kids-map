# 키즈 여행 지도

아이와 가볼 만한 국내 여행지를 테마·지역·주제별로 보는 지도입니다. 가이드북 두 권(권역별 300곳, 주제별 목록)의 장소를 합쳤습니다.

- `index.html`: 지도 페이지 (Leaflet, 지도 © OpenStreetMap contributors)
- `kids-places.csv`: 전체 장소 목록 (장소, 지역, 테마, 주제, 좌표)
- `kids-places-google-mymaps.csv`: 구글 내 지도 가져오기용 파일

좌표 중 일부는 대략 위치이며, 지도에서 점선 테두리 핀으로 표시됩니다.
